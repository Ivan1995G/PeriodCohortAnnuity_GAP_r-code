# The Period-Cohort Annuity Valuation Gap under Mortality Model Uncertainty

Single-population replication repository for:

Giovanna Bimonte, Ivan Gallo, and Maria Russolillo, "The Period-Cohort
Annuity Valuation Gap under Mortality Model Uncertainty", submitted to
*Annals of Actuarial Science* (manuscript AAS-2026-0050).

## Scope

The repository follows the order of the original
`mortality_ensemble_eiopa_clean_full.R` script while separating its major
blocks into auditable modules. It reproduces the mortality validation,
five-model selection, ensemble weights, independent test, final mortality
projection, period/cohort annuity valuation, eight tables, and nine figures
reported in the paper.

The pipeline analyses one population per run. It does not automatically loop
over male, female, and total mortality.

## Requirements

- R 4.5.1, as recorded in `renv.lock`
- HMD account credentials
- Internet access for HMD retrieval
- Sufficient time for repeated rolling-origin and CP-spline estimation

The principal packages are `demography`, `StMoMo`, `dplyr`, `tidyr`,
`tibble`, `purrr`, `ggplot2`, `forecast`, `mgcv`, `svcm`,
`MortalitySmooth`, `readxl`, and `testthat`.

Restore the recorded environment from the repository root:

```r
install.packages("renv")
renv::restore()
```

## Run the Analysis

From the repository root:

```r
source("main.R")
```

or:

```text
Rscript main.R
```

`main.R` executes the following stages in order:

1. load required packages;
2. apply the general configuration;
3. load auxiliary, ensemble, financial, and Camarda functions;
4. retrieve and check HMD data;
5. define the eight mortality models and fit/forecast dispatch;
6. run validation, selection, weights, and the independent test;
7. run the complete financial block;
8. save nine separate graphs and all numerical outputs.

## Financial Component

`R/financial_pipeline.R` starts from the five models selected on validation
data. It refits them through 2019 and projects mortality far enough to follow
each age-67 cohort to age 100. It then:

- reads the exact 31 December 2019 EIOPA euro curves;
- constructs baseline and official up/down discount factors;
- includes the flat 3% benchmark reported in Table 8;
- calculates period and cohort annuity values;
- calculates absolute and relative gaps and correction factors; and
- constructs Tables 4-8 and Figures 6-9.

The financial pipeline is therefore part of the standard `main.R` run and
cannot be skipped when reproducing the paper.

## Generated Files

Graphs are saved separately under:

```text
graph/<population>/figure_1_validation_age67.pdf
...
graph/<population>/figure_9_shapley_stress_gap.pdf
```

No cumulative PDF is created.

Numerical outputs are saved under `output/<population>/`, including:

- `table_1_validation_accuracy.csv` through
  `table_8_flat_vs_eiopa.csv`;
- detailed test and liability CSV files;
- `results_mortality_ensemble_eiopa.rds`; and
- `reproduction_check.csv`.

The RDS file is generated by a full run but is ignored by Git because it can
be several hundred megabytes. The repository retains the lightweight male
verification CSVs and figures; all of them can be regenerated.

## Verification

At the end of each complete run, `R/outputs.R` compares the selected
population's eight generated paper tables with the rounded proof values in
`data/reference/`. The result is written to `reproduction_check.csv`.
Rows marked `review` generate a warning but do not prevent the completed
pipeline from saving its outputs.

The original script contains no `set.seed()` call. Consequently, exact
comparison of stochastic fitting steps must use the same external seed in
both runs. A controlled male-population comparison with seed `20260611`
found a maximum absolute difference of zero for validation accuracy,
ensemble weights, test accuracy by aggregate/age/year, EIOPA term
structures, liability values, and liability summaries. The machine-readable
report is `output/male/original_equivalence_check.csv`.

After producing the two RDS files, repeat the comparison from the repository
root with:

```text
Rscript tests/compare_original_outputs.R
```

Override `ORIGINAL_RDS`, `MODULAR_RDS`, and `COMPARISON_REPORT` when the
files are in different locations. The full protocol and interpretation are
in `VERIFICATION.md` and the repository guide.

Run deterministic unit and structural tests without fitting HMD models:

```r
source("tests/testthat.R")
```

## Included and Excluded Scope

Included code corresponds to the models, ensemble procedures, financial
valuation, tables, and figures reported in the proof.

Excluded blocks are limited to analyses that do not feed any reported
result: pairwise ensemble tests, duration/PV01 diagnostics, maturity-gap
decomposition, and their additional plots. See `SCRIPT_MAPPING.md`.

## Data

HMD mortality data are not redistributed. Each reproducer must obtain an HMD
account. The exact public EIOPA workbook is included in `data/eiopa/`.
Detailed provenance and restrictions are in `DATA.md`.
